# xml-lyrics-maker


Генератор анимированных субтитров «слово за словом» для **Alight Motion**.

## Как работает

1. Вы загружаете XML-шаблон проекта из Alight Motion (в нём должен быть один `<text>`-слой — образец).
2. Вводите текст песни. Каждая строка = новый «сброс»: при переходе на новую строку накопление слов начинается заново.
3. Скрипт генерирует N текстовых слоёв. Внутри одной строки слова накапливаются (`слово`, `слово + слово`, ...). Короткие слова и предлоги склеиваются со следующим словом.
4. Скачиваете готовый XML — импортируете в Alight Motion.

## Настройки

- **Кадров на чанк** — длительность одного шага (по умолчанию 10 кадров ≈ 333 мс при 30 fps).
- **Короткие слова** — список слов, которые приклеиваются к следующему (по умолчанию: `в, на, и, а, с, к, у, о, ...`).
